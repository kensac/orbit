# Saved artifact evaluations

`go run ./cmd/orbiteval --suite cmd/orbiteval/testdata/suite.json --results cmd/orbiteval/testdata/results.json` checks captured run outputs against deterministic reference properties and prints a JSON regression and cost report. To execute the suite through an agent's current charter and active skills, use `go run ./cmd/orbiteval --suite suite.json --replay --url https://orbit.example --agent finance` and set `ORBIT_OIDC_ISSUER` and `ORBIT_OIDC_CLIENT_ID` (or pass `--issuer` and `--client-id`). Add `--grade-with evaluator` to judge cases with `grade` rubrics using a separately configured agent backend. Replay signs in with the device flow and calls the configured backend once per case, plus once per graded case; it can incur model costs. `--timeout` bounds the whole sign-in, replay and grading sequence.

In artifact comparison mode the command reads local files, makes no network requests, fetches no sources, executes no backend and writes nothing except its report to stdout. It exits nonzero for regressions or invalid files. In replay mode, one public API request runs cases sequentially against a single snapshot of the current agent charter and active skills, returning output and reported costs for deterministic checks. Optional grading sends only the selected rubric and candidate output to a separate configured runner, without its charter or skills. The server persists no run, message or artifact for replay or grading. Replay deliberately grants no sources, memory, messages, agent tools, connectors, hooks, sessions or actions. Claude Code receives read-only access to private temporary input and skill files. Replay therefore does not reproduce behavior that depends on those omitted inputs or capabilities, and model output can vary between runs.

A version 1 suite has named `cases`. Each case retains `provenance` (the reference run, charter/skills revision and capture context), `inputs` (the saved input JSON), `checks`, an optional natural-language `grade` rubric and an optional nonnegative `max_cost_usd`. Keep credentials out of fixtures. Names must be unique and the result array must contain exactly one result per case. A missing result is a regression; duplicate and unexpected results are errors.

Each check has an RFC 6901 `pointer`, an `op` and a `value`. `equals` compares JSON values recursively with exact decimal number comparison; `contains` checks a string substring; `count` checks an array length against a nonnegative integer. An empty pointer selects the entire output. Missing fields differ from explicit `null`, and array indices cannot have leading zeros. Unknown operations, fields and malformed pointers are errors. Every number in check values and captured outputs must use at most 1000 characters with an exponent between -1000 and 1000; unsupported numbers are invalid input, including in nested or unselected fields.

Each captured result has a matching `name`, an `output` JSON value and an optional nonnegative `cost_usd`. `known_cost_usd` is the exact decimal sum of costs supplied with the results; `missing_costs` counts absent costs, which are never assumed to be zero. A cost bound fails when the result has no reported cost. Model grade decisions include a short reason, exact reported grading-cost total and `missing_grading_costs` count; grade failures fail the overall report. Reports contain check locations and grade reasons, never the captured output or input contents.

To compare a changed configuration offline, capture its outputs separately under the same case names, then pass that result file to this command with the unchanged reference suite. Input capture can help author cases, but its manifest explains which original context was omitted. For semantic rubric checks, add a `grade` string to selected suite cases and use `--grade-with evaluator`; the evaluator must be a different agent using a separately configured runner. The report includes its bounded decision reason and reported grading cost. A grading model call costs tokens and remains a judgment, not a deterministic check.
